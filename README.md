# FIXIO — Home Services Marketplace

FIXIO is a web-based home services marketplace designed to connect customers with service professionals through a simple, user-friendly platform.

## ✨ Features

- **Service Discovery:** Explore available home services.
- **User-Friendly Interface:** Navigate services through a responsive web interface.
- **Service Booking:** Support the home-service booking workflow.
- **Full-Stack Architecture:** Separate frontend and backend components for organized development.

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Deployment:** Vercel

## 💻 Getting Started

### Prerequisites
- Node.js and npm
- MongoDB connection, if required by the backend

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nidhidev2122/FIXIO.git
   cd FIXIO
   ```

2. Install dependencies separately in the `frontend` and `backend` directories:

   ```bash
   cd frontend
   npm install
   ```

   ```bash
   cd ../backend
   npm install
   ```

3. Configure the required environment variables using the project's expected `.env` settings.

4. Start the frontend and backend using the scripts defined in their respective `package.json` files.
